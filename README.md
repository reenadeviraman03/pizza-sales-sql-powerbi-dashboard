🍕 Pizza Sales Data Analysis & Power BI Dashboard
📌 Project Overview

     This project performs end-to-end data analysis on a Pizza Sales dataset using PostgreSQL for data querying and Power BI for interactive dashboard visualization.

🛠 Tools & Technologies Used

   🐘 PostgreSQL

   📊 Microsoft Power BI

  SQL

  pgAdmin

🎯 Project Objectives

  Calculate key performance indicators (KPIs)

  Analyze daily & monthly order trends

  Identify top & bottom performing pizzas

  Analyze revenue distribution by category and size

  Build an interactive business dashboard

📊 Key KPIs

  Total Revenue

  Average Order Value

  Total Orders

  Total Pizzas Sold

  Average Pizzas per Order

📈 Dashboard Features

   Revenue Trend Analysis

   Category-wise Sales Distribution

   Size-wise Performance

  Top 5 & Bottom 5 Products

Monthly Order Trends

Interactive Filters
