# 🍕 Pizza Sales Data Analysis & Power BI Dashboard

## 📌 Project Overview
This is an end-to-end Data Analytics project analyzing a Pizza Sales dataset using PostgreSQL and Power BI.  
The project focuses on extracting business insights, calculating KPIs, and building an interactive dashboard for decision-making.

---

## 🛠 Tools & Technologies Used
- PostgreSQL
- pgAdmin
- Microsoft Power BI
- SQL

---

## 🎯 Business Objectives
- Calculate key performance indicators (KPIs)
- Analyze daily and monthly sales trends
- Identify top and bottom performing pizzas
- Analyze revenue contribution by category and size
- Build an interactive dashboard for business insights

---

## 📊 Key Performance Indicators (KPIs)
- Total Revenue
- Average Order Value
- Total Orders
- Total Pizzas Sold
- Average Pizzas per Order

---

## 📈 Dashboard Features
- Revenue trend analysis (Daily & Monthly)
- Category-wise revenue distribution
- Size-wise sales performance
- Top 5 & Bottom 5 pizzas by revenue
- Top & Bottom pizzas by quantity and orders
- Interactive filters for better analysis

---



## 🚀 Business Insights Generated
- Certain pizza categories generate higher revenue.
- Medium-sized pizzas are the most frequently ordered.
- Sales peak during specific months.
- A few products consistently underperform and require strategy improvement.

---

## 🧠 SQL Analysis Performed
- Revenue calculation using aggregate functions
- Order trend analysis using date functions
- Percentage revenue contribution analysis
- Top & bottom product performance analysis
- Category and size-level breakdown

---




## 💡 Conclusion
This project demonstrates strong SQL querying skills and the ability to transform raw data into meaningful business insights using Power BI dashboards.
